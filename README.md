# 해피니언 디자이너 양성과정 - 시간표·출결·피드백·과제·결제 관리 시스템

Node.js 내장 모듈만으로 만들어 별도 설치 없이 바로 실행됩니다.

## 실행 방법

```bash
cd academy-app
node seed.js     # 최초 1회: 마스터 계정 + 매장(지역) 14곳 생성
node server.js   # 서버 실행 (http://localhost:3000)
```

브라우저에서 `http://localhost:3000` 접속.

### 기본 계정 (seed.js로 생성됨)

| 역할 | 아이디 | 비밀번호 |
|---|---|---|
| 마스터 | happynian | rlatnsejr1! |

매장 리더(관리자)·강사·수강생 계정은 seed에서 임의로 만들지 않습니다. 첫 화면 "회원가입"에서
본인이 직접 가입 신청 → 리더(매장 리더가 없는 매장은 마스터)가 승인관리 탭에서 승인해야 로그인됩니다.

## 권한 구조 (4단계)

- **마스터**: 전체 시스템 관리, 설정(진화시험 출석률 기준 등)
- **관리자(매장 리더)**: 본인 매장 소속 회원가입 승인, 시간표 관리, 결제 관리, 출석/피드백/과제 관리
- **강사**: 출석 체크, 피드백 작성, 과제 등록/관리 (승인·시간표수정·결제관리 권한 없음)
- **수강생**: 마이페이지, 출석 인증, 과제 제출, 시간표 확인

## 매장(지역) 목록

강남 8곳, 강서 4곳, 수원 1곳, 인천 1곳 (총 14곳)이 `seed.js`에 등록되어 있습니다. 각 매장의
정확한 주소·GPS 좌표는 비워둔 상태이며, **대시보드 → 매장 관리** 화면에서 마스터/관리자가
직접 입력해야 합니다. GPS 좌표를 입력하지 않으면 해당 매장 수강생은 출석 체크인 코드 인증을
사용할 수 없습니다(수동 체크는 계속 가능).

## 구현된 기능

- **시간표**: 월별 캘린더, 금/토/일은 컴팩트하게 표시(월~목 위주 운영). "전국 해피니언 스케줄" 버튼으로
  전국 공통 일정(매주 리더/하퍼/천호장 줌미팅, 월 1회 한국 이타리더단 미팅, 스승님 심연 순회 스케줄) 확인.
  이타리더단 미팅 날짜가 매월 마지막 주 토요일까지 미설정이면 마스터/관리자에게 할일 알림 표시.
  날짜별 대관 등 예외 상황은 시간표 항목의 ✎ 아이콘으로 그 날짜만 개별 수정 가능(원본 기본틀은 유지).
- **출석**: 강사/관리자/마스터가 교시별 6자리 체크인 코드 발급 → 발급 후 60초 이내 제출은 출석,
  초과 제출은 지각으로 자동 처리. 코드는 만료되지 않고 다음 교시 코드가 발급될 때까지 유효하며,
  새 코드가 발급되는 시점에 이전 교시 미제출자는 자동 결석 처리됩니다. 지각/결석이 확정되면
  해당 수강생의 매장 리더 + 같은 매장 강사에게 1회씩 인앱 알림이 갑니다(비용 발생 없음). 수동으로
  지각/보강/병결/행사/결석 처리도 가능합니다.
- **출석 통계**: 상태별 비율/횟수. 마스터가 "설정"에서 진화시험(3·6·9·12월) 응시 자격 출석률 기준을
  입력하면, 기준 미달 수강생 개인 페이지에 경고가 표시됩니다(기준 미입력 시 경고 없음 - 임의 수치를
  기본값으로 넣지 않았습니다).
- **피드백**: 강사가 "수업 종료" 버튼을 누르면 그 수업 수강생 전원에 대한 일괄 피드백 입력창이 바로
  열립니다(당일 완료 유도). 피드백 탭에는 오늘 종료한 수업 중 미작성 피드백 건수가 배너로 표시됩니다.
  강사→수강생 피드백은 다른 강사/관리자/마스터에게 공유되고, 수강생→강사 피드백은 강사에게는
  익명(관리자 이상만 작성자 확인 가능), 수강생끼리도 비공개입니다.
- **과제(선물)**: 마감일시(분 단위) 설정, 마감 D-2/D-1/당일 알림 - 수강생 본인, 등록한 강사/관리자,
  대상 매장 리더까지 확인 가능. 제출된 파일은 로컬 대신 구글 드라이브에 저장되고(설정 시), 제출 현황은
  기존 구글 스프레드시트에 새 탭으로 자동 반영됩니다.
- **결제관리**: 기존처럼 분납/후불/환불 등록 가능. 추가로 "월별 회비 현황" - 1~4Lv/강사코스/세미나
  수강생을 매달 자동으로 리스트업하고, 강남·강서는 입금예정일(매월 10일)이 자동으로 채워집니다
  (수원·인천은 날짜 미정이라 수동 입력). 금액은 임의로 채우지 않고 관리자가 직접 입력합니다.
- **회원가입**: 희망요일/레벨(1~4Lv·강사코스·세미나) 복수선택, 내국인/외국인, 이름(예명)/입금자명(본명)
  구분, 소속 매장 선택 시 리더명 자동 표시, 신분증(외국인 생략 가능, 현금영수증 안내 문구)/통장사본 첨부,
  1~4Lv 신청자는 교육비 입금일 확인 체크 후 가입 가능. 아이디는 가입 시 입력한 휴대폰번호로 고정되며
  별도 변경 기능은 없습니다.
- **로그인**: "아이디 저장"(브라우저에 저장) / "자동 로그인"(체크 해제 시 브라우저를 닫으면 로그아웃) 옵션.

## 체크인 코드에 대한 참고

QR 스캔 대신 **6자리 체크인 코드 + GPS 인증**으로 동일한 목적(짧은 시간 내 본인 인증)을 구현했습니다.
GPS는 브라우저 Geolocation API를 사용하며, 실외에서는 오차 5~20m 수준이지만 실내에서는 위성 신호가
약해 오차가 커질 수 있어(수십~수백m) 매장 위치 등록 시 여유를 두고 설정하는 것을 권장합니다.

## 데이터 저장 방식

`data/db.json` 파일 기반 저장소입니다. 세션도 이 파일에 저장되어 서버가 재시작돼도 로그인이
유지됩니다(Render 무료 플랜의 idle spin-down 대응).

## 실서비스 전환 시 참고

- 파일 업로드: 구글 연동 시 드라이브에 저장, 미연동 시 `uploads/`에 로컬 저장(재배포 시 유실 가능)
- SMS/카카오 알림: 이번 범위에서 제외(웹 내 알림만, 비용 없음). 필요 시 추후 SMS API 연동 가능
- 매장 확장: `regions`에 매장 추가(대시보드 화면에는 아직 매장 추가 UI가 없어 API로 등록 필요) +
  회원가입/시간표에서 바로 선택 가능
