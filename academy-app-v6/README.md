# 아카데미 시간표 · 출결 · 피드백 · 과제 · 결제 관리 시스템 (프로토타입)

그릴미로 정리한 요구사항을 그대로 구현한 동작 가능한 프로토타입입니다. Node.js 내장 모듈만으로 만들어 별도 인터넷 설치 없이 바로 실행됩니다(현재 샌드박스에 npm 레지스트리 접근이 막혀 있어 외부 패키지 없이 구현했습니다. 실제 운영 서버에 배포할 때는 아래 "실서비스 전환 시 참고" 참고).

## 실행 방법

```bash
cd academy-app
node seed.js     # 최초 1회: 마스터/지역대표/관리자 계정 + 기본 시간표 틀 생성
node server.js   # 서버 실행 (http://localhost:3000)
```

브라우저에서 `http://localhost:3000` 접속.

### 기본 계정 (seed.js로 생성됨)

| 역할 | 휴대폰번호 | 비밀번호 |
|---|---|---|
| 마스터 | 01000000000 | master1234 |
| 지역대표(압구정) | 01011111111 | rep1234 |
| 관리자(압구정) | 01022222222 | admin1234 |

강사/수강생은 첫 화면 "회원가입"에서 직접 가입 → 승인관리 탭에서 마스터/지역대표/관리자가 승인해야 로그인됩니다.

## 구현된 기능 (요구사항 대비)

- 5단계 권한: 마스터(전체) / 지역대표(담당 지역 전체) / 관리자(선택 지역, 지역대표 승인 후 활동) / 강사(승인 필요, 과제·출석) / 수강생(프로필 제출 후 승인 대기)
- 월별 시간표: 레벨(1~4Lv, 페어 수강)·요일 기본틀 등록 → 매달 자동 생성, "내부일정" 토글
- 출석: 교시별(1~3교시) 체크, 7종 상태(출석/보강/지각/조퇴/병결/행사/결석), 수동 체크 + 1분 유효 체크인 코드(로그인 계정 + GPS 50m 이내 인증)
- 출결 통계: 학생별 상태별 비율(%) + 횟수, 레벨/이름 필터
- 피드백: 강사·관리자(리더) → 수강생 개인별(수업별), 수강생 → 강사(익명, 관리자만 작성자 확인 가능) — 난이도 단일선택 + 분위기 복수선택 + 자유코멘트
- 과제(선물): 레벨/요일 대상 지정, 데드라인 D-1/D-2/당일 웹 내 알림 배너, 제출방식(파일/링크/둘다/없음) 강사 지정, 자유 코멘트 항상 가능
- 결제관리: 입금자명 별도 필수 기입, 분납 회차별 체크, 후불 플래그, 환불(금액/사유/처리자 기록)
- 수강생 상태: 수강중/퇴사 — 퇴사는 삭제 아닌 숨김 처리(결제기록 등 보존, 목록·열람 차단)
- 비밀번호 찾기: 비용 발생 없는 방식 — 관리자 이상이 임시 비밀번호로 초기화

## QR 출석에 대한 참고

원래 요청은 "QR 코드 스캔"이었으나, 이 환경은 외부 네트워크(npm 등)가 막혀 있어 QR 이미지 생성 라이브러리를 설치할 수 없었습니다. 대신 **1분 유효 6자리 체크인 코드**로 동일한 목적(짧은 시간 내 본인 인증 + GPS 인증)을 구현했습니다. 실제 서버에 배포해 인터넷이 열리면 `qrcode` 패키지를 추가해 이 코드를 QR 이미지로 렌더링하도록 몇 줄만 바꾸면 됩니다(로직은 이미 코드 기반으로 완성되어 있어 교체가 쉽습니다).

## 데이터 저장 방식

`data/db.json` 파일 기반 저장소입니다(별도 DB 설치 없이 바로 동작). 동시 사용자가 많아지면 SQLite/PostgreSQL 등으로 교체를 권장합니다.

## 실서비스 전환 시 참고

- 파일 업로드: 현재 base64로 받아 `uploads/`에 저장 (용량 제한 25MB 요청 본문 기준)
- 세션: 서버 재시작 시 초기화되는 인메모리 세션입니다. 실서비스에서는 Redis 등 영속 세션 저장소 권장
- SMS/카카오 알림: 이번 범위에서 제외(웹 내 알림만). 필요 시 알리고 등 SMS API 연동 가능
- 지점 확장: `regions` 테이블에 지점 추가 + 관리자 계정에 regionId만 지정하면 나머지 구조 변경 없이 다지점 확장 가능
